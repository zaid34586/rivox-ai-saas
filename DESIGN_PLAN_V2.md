# NexaFlow — Design System v1 (Fresh Redesign)

## Brand
- **Name:** NexaFlow
- **Tagline:** Automate the repeat. Ship the new.
- **One-liner:** AI workflow builder for creators — connect apps, generate content, publish across platforms from one canvas.
- **Logo concept:** Abstract "∞" made of two overlapping rounded rectangles (one slate, one violet) forming an infinity loop — flow without end.

## Type
- **Display:** Space Grotesk (variable), 600–800, headlines
- **Body:** Inter, 400–500, 1rem
- **UI / labels:** Inter, 500–600, 0.875rem
- **Mono:** JetBrains Mono, data readouts

## Layout Principles
- Left-aligned hero (not centered)
- Sharp 6px–8px radius, no 9999px pills except badges
- 1px borders as primary structure, not shadows
- One motion moment: hero fade-in on load
- No all-caps eyebrow labels, no numbered markers except real sequences

## Review: Why this isn't "same design"
| Generic SaaS | NexaFlow |
|-------------|----------|
| Emerald/gold | Violet + rose |
| Rounded-everything cards | Sharp panels, 1px borders |
| Centered hero | Left-aligned editorial hero |
| All-caps eyebrows | Sentence case labels |
| Gradient washes | No decorative gradients |
